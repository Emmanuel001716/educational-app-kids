# EduJoy Kids

EduJoy Kids is a child-friendly educational web app designed for learners from Kindergarten to SS3. It features:

- Level-based learning paths for Kindergarten, Primary, JSS, and SS3
- Subject cards for reading, numeracy, science, technology, and social studies
- Interactive quiz practice to reinforce learning
- A simple, colorful, mobile-friendly interface

## How to run

Open `index.html` directly in a browser, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit:

http://localhost:8000

## Project structure

- `index.html` — main app layout
- `styles.css` — styling and responsive design
- `script.js` — learning data and quiz logic

## Learning goal

This app introduces children to fun, age-appropriate learning experiences that build confidence, curiosity, and academic foundation across different school levels.
