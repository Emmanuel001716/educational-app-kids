# EduJoy Kids

EduJoy Kids is a colorful educational web app designed for children from kindergarten through SS3.

Features:
- Age-based learning sections for KG, Primary, JSS, and SS3
- Lesson cards for literacy, numeracy, science, geography, and exam prep
- Interactive quiz challenge for each stage
- Child-friendly design with responsive layout
- Suitable as a starter educational platform for Nigerian schools and learning centers

## Run locally

Open `index.html` directly in your browser or run a local web server:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Project files

- `index.html` — app structure
- `styles.css` — design and responsive layout
- `script.js` — lesson data and quiz logic
