# Learner's Hub

Learner's Hub is a colorful educational web app designed for children from kindergarten through SS3.

## Features

- **Age-based learning paths** for Kindergarten, Primary, JSS, and SS3
- **Lesson cards** for literacy, numeracy, science, geography, and exam prep
- **Interactive quiz challenges** for each educational stage
- **Student dashboard** with progress tracking and daily goals
- **Parent & teacher support** with clear progress reports
- **Mobile-responsive design** works on all devices
- **Child-friendly interface** with colorful, engaging visuals

## Getting Started

### Run locally

Open `index.html` directly in your browser, or run a local web server:

```bash
python3 -m http.server 8000
```

Then open:

```
http://localhost:8000
```

### Login to dashboard

- Go to **Login** page
- Enter any email/student ID and password (demo credentials work)
- Access the student dashboard with progress tracking

## Project structure

- `index.html` — main landing page with features and levels overview
- `login.html` — student login portal
- `dashboard.html` — student dashboard with lessons, progress, and rewards
- `styles.css` — unified styling and responsive design
- `script.js` — login logic and interactive features

## Recommended Deployment

### Deploy to GitHub Pages (free)

```bash
git add .
git commit -m "Deploy Learner's Hub"
git push origin main
```

Then enable GitHub Pages in repository settings.

### Deploy to Netlify (recommended)

1. Connect your GitHub repository to Netlify
2. Build command: (leave empty for static site)
3. Publish directory: `.` (root)
4. Deploy

### Deploy to Vercel

1. Import project from GitHub
2. Click Deploy
3. Get instant live URL
